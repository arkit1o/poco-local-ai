# POCO Local AI — исходники

Стартовый проект локального ИИ-чата для Android на базе `llama.rn`. Платный API-ключ не нужен: модель должна работать на телефоне. Файл модели GGUF в архив не входит.

**Важно:** это исходники, а не готовый APK. Первую сборку нужно проверить в GitHub Actions; могут потребоваться исправления совместимости.

## Загрузка через браузер GitHub
1. Открой https://github.com/arkit1o/poco-local-ai
2. Нажми **Add file** → **Upload files**.
3. Сначала распакуй ZIP. Загрузи все файлы и папки *изнутри* `poco-local-ai`, а не сам ZIP.
4. Нажми **Commit changes**.
5. Открой вкладку **Actions** и выбери **Build Android APK**. Если GitHub предложит включить Actions — включи.
6. После завершения сборки открой запуск workflow и скачай артефакт `poco-local-ai-debug-apk`.

## Модель
Отдельно понадобится совместимая модель `.gguf`. Для начала ищи небольшую instruct-модель 1B–3B в квантовании Q4_K_M, проверив лицензию и источник. Учитывай доступную RAM и место на телефоне. Текущий стартовый интерфейс содержит чат и поле пути к модели; полноценная загрузка модели и выбор файла могут потребовать доработки под конкретное устройство.

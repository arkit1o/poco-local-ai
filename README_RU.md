# POCO AI — автономный ИИ для Android

Это приложение использует локальные GGUF-модели через `llama.rn` / `llama.cpp`. Ключи, подписки и сервер не нужны. После загрузки модели ответы генерируются на телефоне и могут работать без интернета.

## Модели
- **Qwen3 0.6B Q4_K_M** (~484 MB): лёгкая, для проверки на телефоне.
- **Qwen3 1.7B Q4_K_M** (~1.28 GB): рекомендуемый баланс.
- **Qwen3 4B Q4_K_M** (~2.5 GB): экспериментальная; может не хватить свободной RAM на варианте 8 GB.

Модели не включены в APK, иначе установочный файл был бы огромным. Загрузка делается из Hugging Face внутри приложения. После загрузки модель остаётся на устройстве.

## Что готово в проекте
- чат на русском;
- локальная история;
- выбор и скачивание нескольких моделей;
- прогресс скачивания;
- переключение между скачанными моделями;
- локальный инференс без API;
- GitHub Actions для облачной сборки APK.

## Сборка APK
Workflow `.github/workflows/build-apk.yml` запускается после загрузки проекта в GitHub. Он создаёт Android-проект, собирает release APK и прикрепляет его к завершённому запуску как artifact.

Ограничение: я не могу из этой среды создать репозиторий GitHub от имени пользователя или выдать APK, не запустив реальную Android-сборку. Этот архив содержит исходники и автоматизированную конфигурацию сборки, а не готовый APK.

## Требования
- Node.js 20+
- Expo SDK 54 / React Native 0.81
- Android build выполняется в GitHub Actions с Java 17 и Android SDK.

## Лицензии
Приложение — собственный код. `llama.rn` распространяется по лицензии MIT. Модели Qwen3 опубликованы с лицензией Apache-2.0 в репозиториях, указанных в `src/models.ts`. Проверьте лицензии и карточки модели перед коммерческим использованием.
